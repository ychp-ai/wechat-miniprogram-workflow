# feature · 业务功能

## 输入与执行

从用户指定功能入手，检查涉及页面、组件、接口和验收条件。只实现这条流程，复用现有设计与架构，包含必要的加载、空数据、失败反馈、表单校验和重复操作处理。接口缺失时明确阻塞点；用户接受模拟时可实现明确标注的模拟模式，不把模拟成功当作真实接入。

按需使用 miniprogram-development。涉及 CloudBase 业务可读取对应已安装技能，但不自动启动云部署或其他节点。已有自建后端按其合同实现。

## 交付

指定功能代码、相关的必要验证，以及接口/配置缺项。验证覆盖该流程的成功与主要失败分支；区分静态检查、模拟测试和真实接口验证。

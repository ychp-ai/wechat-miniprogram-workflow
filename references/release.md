# release · 预览与发布

## 输入与执行

明确本次动作是准备、预览、上传体验版、提交审核还是正式发布；“发布准备”只生成准备产物。检查实际 AppID、目标环境、代码版本、构建方式和已有验收证据，不强制重跑整个测试节点。需要时读取 miniprogram-development 的相关本地工具说明，并用已安装工具 help 或官方文档核对命令。

技能安装不代表 IDE、CLI、签名材料或登录权限可用。先完成可执行的准备和本地检查；实际上传、提审、发布仅在用户对该动作和目标已有授权时执行，不重复索取已有授权。目标存在歧义时先明确，不猜环境。不要顺带部署云函数。区分请求已提交与平台已审核/发布成功；不自动重复可能已成功的提交，先检查状态。

## 交付

release.md：目标、版本、操作与返回状态、预览产物或平台版本标识、剩余步骤。没有工具、账号权限或授权时明确完成到哪一步，不声称已经发布。
